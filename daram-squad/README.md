# 🌰 다람 원정대

다람 대장을 끌어서 움직이고, 도토리를 모아 진지를 키우고, 친구들과 함께 슬라임 둥지를 무너뜨리는 **3D 원정 게임**임.
파일 하나(`index.html`)로 끝나며 외부 라이브러리·CDN·글꼴을 전혀 쓰지 않음.
학교 인터넷이 CDN을 막아도, 인터넷이 끊겨도 그대로 돌아감.

> **독자적으로 제작한 게임임.** "대장을 끌어 움직임 → 재화 수집 → 발판에서 구매 → 부대 모집 → 적 진지 격파"라는
> 장르의 규칙만 참고했고, 이름·캐릭터(다람쥐·슬라임)·그림·길 구성·화면 디자인은 모두 새로 제작함.
> 특정 상용 게임의 복제본이 아님.

## ▶️ 바로 해 보기

| 방법 | 주소 |
|------|------|
| 로컬 파일 | `daram-squad/index.html`을 크롬·엣지·사파리로 열기 (더블클릭) |
| GitHub Pages | `https://dasooni-jpg.github.io/geulssugi-mirror/daram-squad/` (main에 합쳐진 뒤) |
| Cloudflare | 아래 "온라인 주소 만들기" 참고 |

**성공 화면**: 크림색 카드에 "다람 **원정대**" 제목, 다람쌤 그림, 길 카드 3장(🍂 가을 숲길 · 🌸 벚꽃 언덕 · 🌙 달빛 호숫가),
보라색 **▶ 원정 출발!** 단추가 보이면 정상임. 카드 뒤로는 3D 진지가 천천히 돌아감.
단추를 누르면 "🍂 가을 숲길 — 원정 출발!" 알림과 함께 놀이가 시작됨.

## 🎮 놀이 방법

| 순서 | 하는 일 |
|------|---------|
| 1 | 화면을 **끌어서**(또는 방향키·WASD) 다람 대장을 움직임 |
| 2 | 바닥의 **도토리**를 주움 (가까이 가면 저절로 딸려 옴) |
| 3 | 둥근 **나무 발판 위에 서 있으면** 도토리가 들어가고, 다 차면 건물이 서거나 힘이 세짐 |
| 4 | 훈련 텐트에서 **친구들**이 찾아와 대장을 따라다니며 함께 싸움 (공격은 자동) |
| 5 | 길을 따라가 **슬라임 둥지**를 무너뜨리면 그 자리가 새 진지가 됨. 둥지 뒤는 보라색 **끈적 벽**이 막고 있어 건너뛸 수 없음 |
| 6 | 마지막 마당의 **슬라임 대왕**을 쓰러뜨리면 길을 되찾음 |

- 공격 단추는 없음. 사거리 안에 슬라임이 들어오면 대장과 친구들이 알아서 도토리를 던짐.
- 대장이 지치면 3초 뒤 진지에서 다시 출발함. 잃는 것은 시간뿐임.
- **모닥불 곁**(점선 고리 안)에 서 있으면 체력이 빠르게 참.
- `Esc` 또는 `P`, 화면 오른쪽 위 ⏸ 단추로 잠깐 멈춤.

### 발판 5가지

| 발판 | 하는 일 | 열리는 때 |
|------|---------|-----------|
| 🏕️ 훈련 텐트 | 도토리 다람(노란 털모자)이 찾아옴. 올릴수록 정원 3 → 10마리 | 처음부터 |
| 🛡️ 방패 오두막 | 방패 다람(파란 투구)이 앞에서 막아 줌. 정원 1 → 4마리 | 첫 둥지를 무너뜨린 뒤 |
| 🎯 새총 나무집 | 새총 다람(분홍 뾰족모자)이 멀리서 세게 쏨. 정원 1 → 4마리 | 둘째 둥지를 무너뜨린 뒤 |
| 💥 도토리 힘 | 모두의 공격력 +25%씩 (5단계) | 처음부터 |
| ❤️ 튼튼 간식 | 모두의 체력 +25%씩 (5단계) | 처음부터 |

### 슬라임 7가지

| 이름 | 특징 |
|------|------|
| 초록 슬라임 | 통통 튀어 와서 부딪힘 |
| 뿜뿜 슬라임(보라) | 멀리서 끈적이를 뱉음. 계속 움직이면 피할 수 있음 |
| 가시 슬라임(주황) | 작고 빠름 |
| 덩치 슬라임(파랑) | 느리지만 튼튼하고 아픔 |
| 뿜뿜 버섯 | 움직이지 않고 포자를 쏨 |
| 슬라임 둥지 | 싸우는 동안 슬라임을 계속 낳음. 무너뜨리면 남은 슬라임이 한꺼번에 터짐 |
| 슬라임 대왕 | 빨간 원이 보이면 내려찍기 예고 → 원 밖으로 피함. 2·3번 길에서는 끈적 폭탄도 던짐 |

## 🗺️ 길 3개

| 길 | 구성 | 봇 완주 시간* | 별 3개 / 2개 기준 |
|----|------|--------------|-------------------|
| 🍂 1. 가을 숲길 | 둥지 3 + 대왕 | 약 3분 20초 | 4:10 / 6:30 |
| 🌸 2. 벚꽃 언덕 | 둥지 3 + 대왕(끈적 폭탄) | 약 5분 | 6:10 / 9:20 |
| 🌙 3. 달빛 호숫가 | 둥지 4 + 대왕(폭탄·부하) | 약 6분 30초 | 7:40 / 11:40 |

\* 발판을 고르게 사고 체력이 낮으면 물러나는 자동 플레이 봇으로 길마다 5번씩 잰 값임. 사람이 직접 한 기록이 아니므로, 학생이 실제로 걸리는 시간은 교실에서 확인이 필요함(더 오래 걸릴 것으로 예상함).
앞 길을 되찾아야 다음 길이 열림.

## 💾 이어서 하기 (8분 이용권 대비)

- 놀이 중 **4초마다**, 그리고 둥지를 무너뜨릴 때마다 진행 상황을 그 기기에 적어 둠.
- 창이 닫혀도 다음에 열면 첫 화면에 **▶ 이어서 하기**가 나오고, 마지막으로 차지한 진지에서 건물·도토리·친구들을 그대로 갖고 출발함.
- 새로 하고 싶으면 옆의 **↻ 처음부터**를 누름.
- 적어 두는 것은 "몇 번 길 · 몇 번째 진지 · 발판 단계 · 도토리 수 · 걸린 시간"뿐임.

## 🔒 개인정보 (설계 원칙)

- 이름·별명·사진·이메일을 **입력받지도 저장하지도 않음.**
- 길별 최고 기록, 소리 켜짐/꺼짐, 이어하기 기록만 **그 기기의 브라우저**(`localStorage`의 `daramSquad.v1`)에 남음.
- 서버로 보내는 것이 없음. 생성형 AI 호출도 없음.

## 🌐 온라인 주소 만들기 (Cloudflare Worker, 1회)

> **가장 쉬운 길**: `daram-squad-cloudflare.zip` 을 받아 풀면 `1-읽어보세요.txt` 와 함께
> **방법 A(Pages에 폴더 끌어다 놓기)** · **방법 B(Worker에 붙여넣기)** 두 폴더가 나옴. 둘 중 하나만 하면 됨.

`daram-squad-worker.js` 하나에 게임 화면과 다람쌤 그림이 모두 들어 있음.

1. Cloudflare 대시보드 → **Workers & Pages → Create → Worker** (이름 예: `daram-squad`)
2. 편집기의 내용을 모두 지우고 **`daram-squad-worker.js` 전체를 붙여넣기 → Deploy**
3. 주소창에 `https://daram-squad.<계정이름>.workers.dev` 를 넣어 첫 화면이 보이면 성공임

화면(`index.html`)을 고친 뒤에는 이 폴더에서 아래 명령으로 워커 파일을 다시 만듦.

```bash
node build-daram-squad-worker.mjs      # → daram-squad-worker.js 갱신
```

> PowerShell로 파일을 클립보드에 담을 때는 `Get-Content -Raw -Encoding UTF8` 로 읽을 것.
> 인코딩 옵션 없이 읽으면 한글이 깨져 `Uncaught SyntaxError` 가 남.

### 다람연산·탐수학 상점에 넣으려면

주소가 생긴 뒤 두 곳에 같은 id로 한 줄씩 넣음(값은 예시).

```js
// daram-worker.template.js 의 GAME_CATALOG
daramSquad: {
  id: "daramSquad", name: "다람 원정대", icon: "🌰", launchMode: "embed",
  url: "https://daram-squad.<계정이름>.workers.dev/",
  plans: { minutes8: { id: "minutes8", name: "8분권", price: 120, plays: 0, timeTickets: 1, minutes: 8 } },
},
// daram-app.html 의 GAME_SHOP
{ id: 'daramSquad', icon: '\u{1F330}', name: '다람 원정대', launchMode: 'embed',
  plans: [{ id: 'minutes8', mode: 'time', icon: '⏱️', name: '8분권', desc: '시작한 순간부터 8분 동안 놀 수 있어요.', price: 120 }] },
```

iframe 안에서도 그대로 작동함. 이어하기 기록이 기기에 남으므로 8분이 끝나도 다음 이용권으로 이어서 할 수 있음.

## 🧰 교실에서 쓸 때 팁

- **소리**: 첫 화면의 `🔊 소리 켜짐` 또는 놀이 중 오른쪽 위 `🔊` 단추로 끔. 선택은 기기에 기억됨.
  다른 창으로 넘어가면 놀이가 멈추고 소리도 함께 꺼짐.
- **기기가 느릴 때**: 따로 설정할 것 없음. 버거워하면 화면 해상도를 스스로 낮추고, 그래도 느리면 그림자를 끔.
- **가로 화면 권장**: 태블릿·크롬북 가로 화면에서 가장 보기 좋음. 세로 휴대폰도 됨(조금 멀리서 봄).
- **막혔을 때 해 줄 말**: "둥지 앞에서 도토리를 더 모아서 발판을 올리고, 친구가 다 모인 뒤에 다시 가 보자."
  발판을 하나도 안 올리면 2·3번 길은 깨기 어렵게 만들어 둠.

## 🛠 값을 고치고 싶을 때

`index.html` 안에 한국어 주석과 함께 아래 순서로 들어 있음. **게임의 세기·값·길 모양은 4번 한곳에 모여 있음.**

| 부분 | 내용 |
|------|------|
| 화면 스타일 | HUD·첫 화면·결과 화면 CSS |
| 1. 행렬 수학 | 카메라(4×4)와 물체(3×4) 행렬 |
| 2. WebGL 렌더러 | 셰이더, 도형 빌더, 인스턴싱(같은 모형을 한 번에 그림), 평면 그림자 |
| 3. 모형 만들기 | 다람쥐·슬라임·건물·나무를 공·원기둥·상자로 조립 |
| **4. 놀이 규칙 값** | **`UNITS`(체력·공격·속도) · `PADS`(발판 값·정원) · `STAGES`(길·둥지·별 기준) · `THEMES`(색)** |
| 5. 소리 | 효과음과 배경 음악을 그 자리에서 합성 |
| 6. 길과 풍경 | 조종점 → 곡선 → 통로·땅 그림·나무 배치 |
| 7. 놀이 진행 | 대장·친구·슬라임의 움직임, 싸움, 도토리, 발판, 이어하기 |
| 8~9. 화면 그리기 | 3D 장면, 체력 막대·말풍선·화살표 |
| 10~12. 조작·화면 흐름 | 끌기/키보드, 첫 화면·멈춤·결과, 매 프레임 갱신 |

자주 고칠 만한 것:

- **너무 어려움/쉬움** → `STAGES` 각 길의 `mult: { hp, dmg }` (슬라임 체력·공격 배율)
- **발판 값** → `PADS` 의 `costs` 배열 (예: 텐트 첫 값 `5`)
- **정원** → `PADS` 의 `caps` 배열
- **별 기준 시간** → `STAGES` 의 `par: [별3개 초, 별2개 초]`
- **새 길 추가** → `STAGES` 에 항목을 하나 더 넣음. `pts`(길 조종점), `camps`(둥지 자리 `s`와 지킴이), `patrols`, `theme`
  - 둥지 사이 간격은 길 따라 50 안팎, 마지막 대왕 자리 뒤로 25 이상 길이 남아야 함
  - 길을 너무 급하게 꺾지 말 것(조종점 사이 x 차이 12 이내 권장) — 통로끼리 겹치면 나무 벽이 사라짐

## ✅ 점검한 것

- 헤드리스 크롬에서 실제 실행: 콘솔 오류 0건
- 흐름 42항목 통과: 끌기·키보드·실제 터치 조작, 발판 결제, 훈련, 멈춤, 쓰러짐/되살아남, 이어하기, 끈적 벽, 결과·기록 저장, 길 잠금 해제
- 자동 플레이 봇으로 3개 길을 5번씩(15회) 모두 완주, 좌표 오류·통로 이탈 0건
- 텐트만 짓고 발판을 더 올리지 않은 채 돌진하는 봇: 1번 길은 약 12분·9번 쓰러진 끝에 완주, 2·3번 길은 30분 안에 대왕을 넘지 못함 → 발판을 올려야 깨지도록 의도한 난이도임
- 화면 크기 4종(1024×768 · 390×844 · 844×390 · 1600×900) 배치 확인
- 워커 파일이 `index.html`·`mascot.png`와 바이트까지 같은 내용을 내려 주는지 확인

실제 태블릿·크롬북에서의 손맛(속도감, 소리 크기)은 기기에서 직접 확인이 필요함.
