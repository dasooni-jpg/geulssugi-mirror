# 수담(數談) v2 — 논쟁 지속형 수학 토론 소프트웨어

초등학교 6학년 1학기 수학 토론 수업용 웹앱입니다.
**학생 전원의 주장과 근거를 익명으로 한 화면에 동시에 띄우고, 토론 전후 입장 변화를 기록합니다.**

> **이 폴더만 복사해서 `index.html` 을 더블클릭하면 인터넷·서버 없이 바로 실행됩니다.**

## v1에서 무엇이 바뀌었나

v1은 토론을 담는 그릇은 있었으나 토론이 끝나지 않게 하는 장치가 없었습니다.
실제 적용에서 3~4차시 만에 정답이 수렴되어 토론이 종료되었습니다. v2는 이 문제를 해결합니다.

| 항목 | v1 | v2 |
|---|---|---|
| 정답 판정 | 정오 표시 있음 | **정오 표시 삭제** — 앱은 채점하지 않음 |
| 입력 단위 | 답만 입력 | **주장 + 근거 동시 입력** (근거 없으면 제출 차단) |
| 개입 장치 | 없음 | **반례 카드 투입** (질문만, 답 없음) |
| 기록 | 최종 응답만 | **1차·2차 입장 모두** + 변경 사유 |
| 의견 배치 | 작성 순서 | **소수 의견 우선 배치** |

## 기능 (F1~F8)

| 번호 | 기능 | 구현 |
|---|---|---|
| F1 | 익명 병렬 보드 | 전원 카드를 한 화면에 요약 표시, 클릭하면 전문 확대. 별명만 노출 |
| F2 | 주장·근거 분리 입력 | 근거 칸이 비면 제출 버튼이 눌리지 않음 |
| F3 | 근거 태그 투표 | E1~E5 태그 + 다른 카드에 동의/반론 |
| F4 | 반례 카드 투입 | 교사가 수동 투입, 또는 AI 생성(교사 서버 경유). 질문만 담음 |
| F5 | 1차·2차 재투표 | 입장이 바뀌면 변경 사유(R1~R4)를 반드시 고르게 함 |
| F6 | 교사 실시간 대시보드 | 미참여자·근거 분포·쏠림 비율·반론 수, 임계값 초과 시 경고 |
| F7 | 문제 출제 보드 | 자기 점검표 3개를 모두 표시해야 제출 가능 |
| F8 | 3단계 폴백 | 서버 경유 → 실패 시 내장 발문 → 텍스트 입력 단독 |

## 절대 제약 (C1~C10) 준수 방식

| 번호 | 제약 | 지킨 방법 |
|---|---|---|
| C1 | 브라우저 저장소 미사용 | `localStorage`·`sessionStorage`·`IndexedDB` 를 코드에서 한 번도 쓰지 않음. 상태는 메모리 변수만 |
| C2 | 실명·사진·이메일·전화번호 미저장 | 데이터 구조에 해당 필드 자체가 없음. 출석번호+별명만 |
| C3 | 학생 기기에서 AI 직접 호출 금지 | 학생 화면에는 외부 AI 주소가 없음. 반례 카드·받아쓰기는 교사 서버가 호출 |
| C4 | 정답 표시·채점 금지 | 정오 표시 UI가 없음. 앱은 어떤 응답도 옳다/그르다고 판정하지 않음 |
| C5 | 반례 카드에 결론 금지 | 사전 발문 60개의 반례 카드는 전부 질문형. AI 생성도 질문만 쓰도록 지시 |
| C6 | 시작 화면에 보고서 제목·대상 학년 | 머리글에 항상 표시 |
| C7 | 시도명·학교명·직위·성명 미표시 | 화면·파일명·코드 어디에도 없음 |
| C8 | 외부 프레임워크 미사용 | 화면은 바닐라 HTML/CSS/JS. 교사 서버도 `http`·`fs`·`path` 만 사용 → **npm install 불필요** |
| C9 | 통신 실패가 입력을 막지 않음 | 모든 서버 호출이 실패해도 화면은 로컬 상태로 계속 동작 |
| C10 | 교사 설정값 분리 | 보고서 제목·쏠림 임계값·학급 인원·서버 주소를 ⚙ 설정에서 변경 |

## 폴더 구조

```
sudam/
├─ index.html          ← 더블클릭 = 오프라인 단독 실행 (발문 60개 내장)
├─ README.md
├─ server/             ← 교실 안 노트북용 교사 서버 (의존성 0개)
│  ├─ server.js  ·  package.json  ·  .env.example  ·  .gitignore
└─ cloudflare/         ← 인터넷 상시 배포용 Cloudflare Worker
   ├─ sudam-worker.template.js   ← 워커 원본
   ├─ build-sudam-worker.ps1     ← index.html 을 워커에 주입
   ├─ sudam-worker.js            ← 빌드 결과 (Cloudflare 에 붙여넣는 파일)
   └─ sudam-worker.txt           ← 같은 내용 (메모장으로 열기 편한 사본)
```

## 실행 방법

### ① 파일 단독 실행 (설치·인터넷 불필요)

`index.html` 을 더블클릭합니다. 한 화면 안에서 **선생님 역할과 학생 역할을 오가며** 모든 기능을 확인할 수 있습니다.
⚙ 설정의 **「시연용 응답 30명 채우기」** 로 F1(30명 표시)·F6(쏠림 경고)을 바로 볼 수 있습니다.

> 여러 기기가 같은 방에 함께 들어오려면 아래 ②·③ 중 하나가 필요합니다.
> 브라우저 보안 정책상 파일 실행(`file://`)만으로는 기기 간 데이터 공유가 불가능합니다.

### ② 교실 안 교사 서버 (수업 운영)

```bash
cd server
node server.js
```

`npm install` 이 필요 없습니다(외부 라이브러리를 쓰지 않음).
학생 태블릿에서 `http://<교사 노트북 IP>:3000` 으로 접속합니다.
AI 반례 카드를 쓰려면 `.env.example` 을 `.env` 로 복사해 `GEMINI_API_KEY` 를 넣으세요.
키가 없어도 토론 기능은 모두 동작하며, 반례 카드만 사전 준비본을 씁니다.

### ③ Cloudflare Worker (인터넷 상시 운영)

1. `cd cloudflare` → `powershell -ExecutionPolicy Bypass -File build-sudam-worker.ps1`
2. **Workers & Pages → Create → Worker** 만들고 **Edit code** 에 `sudam-worker.js` 전체 붙여넣기 → Deploy
3. **Settings → Bindings → Add → D1 Database** : Variable name 을 반드시 **`DB`** 로
   (D1 을 연결해야 여러 기기가 같은 방에 들어올 수 있습니다)
4. **Settings → Variables and Secrets**
   - Secret `GEMINI_API_KEY` (선택 — 없으면 준비된 반례 카드로 동작)
   - Text `CLASS_CODE` (교실 코드 4자리)

## 수업 흐름 (대표 수업 6차시 기준)

| TORON | 화면 | 하는 일 |
|---|---|---|
| T 생각 세우기 | 학생 입력 | 논제를 보고 1차 입장(A~D)·주장·근거·근거 태그를 올림 |
| O 풀이 열기 | 공유 칠판 | 전원 카드를 동시에 봄. **소수 의견이 맨 위에** 옴 |
| R 근거 다투기 | 공유 칠판 | 카드를 눌러 동의·반론. 교사가 반례 카드 투입 |
| O 생각 모으기 | 재투표 | 2차 입장을 다시 정하고, 바뀌었으면 사유를 고름 |
| N 문제 만들기 | 문제 출제 보드 | 자기 점검표를 확인하고 논쟁이 될 문제를 냄 |

## 자료 내보내기

⚙ 설정에서 CSV 두 종을 내려받습니다. **데이터 수집 양식의 시트 형식과 동일합니다.**

- `수담_입장변화_N차시.csv` → 「2.입장변화」 시트
  (차시, 출석번호, 별명, 과제유형, 1차입장, 2차입장, 변경여부, 변경사유, 1차근거, 2차근거, 근거변화)
- `수담_근거태그_N차시.csv` → 「3.근거태그」 시트
  (차시, 출석번호, 별명, 사용근거, 반론제기수, 반론피격수, 발언횟수)

## 코드표

| 입장 | 변경 사유 | 근거 유형 | 과제 유형 |
|---|---|---|---|
| A 첫 번째 주장 | R1 친구 근거가 타당 | E1 계산 | T1 판단형 |
| B 두 번째 주장 | R2 반례를 보고 | E2 그림·모형 | T2 반직관형 |
| C 제3의 주장 | R3 계산을 다시 | E3 정의·약속 | T3 다표현형 |
| D 판단 보류 | R4 이유 없이 | E4 반례 | (T4 정의형) |
|  | R0 바꾸지 않음 | E5 실생활 |  |

## 발문 은행

6개 단원 × 10개 = **60개**를 `index.html` 안에 상수로 내장했습니다(외부 파일을 읽지 않으므로 파일 실행에서도 안전).
교사 설정에서 차시를 고르면 재구성표에 맞는 단원·유형이 자동으로 걸러집니다.
단원을 바꾸어도 같은 상호작용이 그대로 작동하므로 재개발이 필요하지 않습니다.

## 제출 관련 메모

- 시작 파일은 `index.html`, 폴더 구조 그대로 USB `program/` 에 넣습니다. `server/`·`cloudflare/` 는 `source/` 로도 씁니다.
- **`node_modules/`·`.git/` 는 제출 폴더에 넣지 않습니다.** v2 는 외부 라이브러리를 쓰지 않아 `node_modules` 자체가 필요 없습니다.
- 소프트웨어 형태(웹앱/앱)는 미확정 상태이며, 본 폴더는 웹앱 기준입니다.
