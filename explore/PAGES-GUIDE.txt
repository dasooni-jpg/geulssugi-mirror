다람 탐험대 — Cloudflare Pages로 옮기기 안내서
=============================================
(2026년 10월 확인 기준. Cloudflare 화면 메뉴 이름은 바뀔 수 있음)

■ 먼저 결론
  1. 지금 쓰는 워커(daram-explore.dasooni.workers.dev)는 그대로 써도 됨.
     - Cloudflare가 2026년 9월 4일부터 무료 워커의 "압축 3MB 한도"를 없앰.
     - 지금은 압축 전 크기 64MiB까지 올릴 수 있음(무료·유료 동일).
     - 다람 탐험대 워커 파일은 약 4MB라 여유가 충분함.
  2. Pages로 옮기면 좋은 점
     - 코드 편집기에 붙여넣기 대신 폴더를 끌어다 놓기만 하면 됨.
     - 파일 하나당 25MiB까지 올릴 수 있음.
  3. Pages로 옮길 때 꼭 알아 둘 점
     - 주소가 바뀜: ○○.workers.dev → ○○.pages.dev
     - 학생 진행 기록은 브라우저에 "주소별로" 저장됨.
       → 새 주소에서는 처음부터 시작함(예전 주소의 기록은 그대로 남아 있음).
     - 학기 중간보다는 새 학기·새 단원을 시작할 때 옮기는 것을 권장함.

■ 준비물
  - Cloudflare 계정(지금 워커를 만든 계정 그대로 사용)
  - 이 묶음의 "방법B-페이지스에-올리기" 폴더(index.html 한 파일, 약 4MB)

■ 처음 올리기 (5분)
  1. https://dash.cloudflare.com 접속 → 로그인
  2. 왼쪽 메뉴 "Workers & Pages" 클릭
  3. "Create application" 클릭 → Pages 쪽의 "Get started" → "Drag and drop your files" 선택
  4. Project name 입력(영어 소문자·숫자·하이픈) 예: daram-explore
     → 주소가 https://daram-explore.pages.dev 가 됨(이미 쓰는 이름이면 다른 이름으로)
  5. "Create project" 클릭
  6. "방법B-페이지스에-올리기" 폴더를 화면의 상자에 끌어다 놓음(zip 파일도 가능)
  7. 파일 목록에 index.html이 보이면 "Deploy site" 클릭
  8. 완료 화면의 주소를 눌러 확인 → 로딩 막대가 찬 뒤 탐험가와 구름 섬이 보이면 성공

■ 새 버전으로 바꾸기 (다음부터)
  1. Workers & Pages → 만든 Pages 프로젝트 선택
  2. "Create a new deployment" 클릭 → Production 선택
  3. 새 "방법B-페이지스에-올리기" 폴더를 끌어다 놓고 "Save and Deploy"
  → 주소가 그대로라 학생 진행 기록도 그대로 이어짐

■ 옮긴 뒤 할 일
  1. 학생들에게 새 주소를 알려 줌(QR 코드로 만들어 칠판에 붙이면 편함)
  2. 교사 설정을 바꿔 두었다면: 예전 주소에서 톱니바퀴 → 교사 설정 → "설정 코드" 복사
     → 새 주소에서 같은 칸에 붙여 넣고 "붙여 넣은 코드 적용"
     (또는 "학급 링크 복사"로 만든 새 주소 링크를 학생에게 나눠 주면 자동 적용)
  3. 예전 워커는 지우지 않아도 됨(예전 기록을 보고 싶은 학생이 있을 수 있음)

■ 올릴 수 있는 크기 (Cloudflare 공식 문서 기준)
  - Pages 끌어다 놓기: 파일 1,000개까지, 파일 하나당 25MiB까지
  - Pages 무료 요금제: 사이트당 파일 20,000개까지
  - Workers: 압축 전 64MiB까지(2026-09-04 변경)

■ 문제가 생기면
  - 예전 화면이 보임 → 새로고침, 또는 탭을 닫고 다시 열기
  - 화면이 하얗게 멈춤 → 폴더 안에 index.html이 맨 위에 있는지 확인
    (폴더 안의 폴더 안에 들어 있으면 주소/폴더이름/ 으로 들어가야 함)
