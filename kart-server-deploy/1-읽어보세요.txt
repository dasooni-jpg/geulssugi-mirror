  우리 반 카트 그랑프리 - 방 서버 올리기 꾸러미
==========================================================

■ 이 꾸러미는 무엇인가요?

  "친구들과 함께 달리기"(최대 8명) 모드를 쓰려면
  중계해 주는 방 서버가 하나 필요합니다.
  이 꾸러미는 그 서버를 클라우드플레어에 올려 주는 도구입니다.

  ※ 혼자 달리기 / 둘이 나눠 달리기 / 기록 도전 은
     이 서버가 없어도 그냥 됩니다. 안 하셔도 게임은 돌아갑니다.


■ 먼저 알아두실 것 (중요)

  클라우드플레어 워커스 화면에는 "압축파일을 끌어다 놓는 칸"이
  없습니다. 그래서 이 꾸러미는 클라우드플레어 화면에 올리는 것이
  아니라, 압축을 풀고 파일을 두 번 누르면 컴퓨터가 알아서
  올려 주는 방식입니다.

  화면에서 손으로 하려고 하면 "Durable Object" 목록이 계속
  비어 있어서 막힙니다. 그 목록은 이미 만들어진 것만 보여 주는데,
  우리 것은 아직 안 만들어졌기 때문입니다.
  아래 방법으로 하면 만드는 것부터 연결까지 한 번에 됩니다.


■ 하는 방법 (3단계, 5분)

  1) 이 압축파일을 바탕화면에 풀어 주세요.
     (파일에 오른쪽 클릭 → "압축 풀기" → "압축 풀기")

  2) 풀린 폴더를 열고,

       윈도우 쓰시면   →   2-윈도우-배포하기.bat    두 번 누르기
       맥 쓰시면       →   2-맥-배포하기.command    두 번 누르기

     ※ 윈도우에서 파란 경고창("Windows의 PC 보호")이 뜨면
        "추가 정보" → "실행"을 누르시면 됩니다.
     ※ 맥에서 "확인되지 않은 개발자" 경고가 뜨면
        파일에 오른쪽 클릭 → "열기" → "열기" 를 누르시면 됩니다.

  3) 검은 창이 열립니다. 그대로 두고 기다리세요.
     - 브라우저가 저절로 열리면 파란 [Allow] 단추를 눌러 주세요.
     - 다시 검은 창으로 돌아와 1~2분 기다리면 끝납니다.


■ 잘 됐는지 확인하는 법

  브라우저 주소창에 아래 주소를 넣어 보세요.

      https://kart.dasooni.workers.dev/api/health

  화면에    {"ok":true, ...}          가 보이면 성공입니다.
  화면에    durable_object_not_bound  가 보이면 아직 안 된 것입니다.

  성공했으면 게임에서 아무것도 더 하실 것이 없습니다.
  서버 주소는 게임 안에 이미 적어 두었습니다.


■ Node.js 가 없다고 나오면

  https://nodejs.org 에 들어가서 왼쪽 초록 단추(LTS)를 눌러
  설치한 뒤, 2)번부터 다시 하시면 됩니다.
  설치 중 나오는 선택지는 전부 [다음]으로 두시면 됩니다.


■ 컴퓨터에 아무것도 설치하기 싫으시다면 (더 쉬운 길)

  클라우드플레어가 대신 실행하게 할 수도 있습니다.
  이미 설정은 거의 다 되어 있고, 아래 한 칸만 맞으면 됩니다.

    클라우드플레어 → 워커스 → kart → 설정 → 빌드

      루트 디렉터리 : (비움)                   ← 이미 비워 두셨음
      빌드 명령     : (비움)
      배포 명령     : npx wrangler deploy      ← 이미 맞음
      프로덕션 분기 : claude/kart-racer-multiplayer-game-rvacck
                      또는 main

  이 상태에서 그 분기에 새 커밋이 올라가면 자동으로 올라갑니다.
  ("배포" 탭에서 [재시도]를 눌러도 됩니다.)


■ 폴더 안의 파일들

  2-윈도우-배포하기.bat    윈도우에서 두 번 누르는 파일
  2-맥-배포하기.command    맥에서 두 번 누르는 파일
  kart-online-worker.js    실제로 올라가는 서버 프로그램
  wrangler.toml            어디에 어떻게 올릴지 적어 둔 설정
  1-읽어보세요.txt         이 문서


■ 개인정보

  이 서버가 주고받는 것은 별명(최대 8글자), 카트 색,
  카트의 위치와 속도뿐입니다.
  실명, 사진, 이메일, 전화번호는 받지도 저장하지도 않습니다.
  모두 나가면 방은 즉시 사라지고 아무 기록도 남지 않습니다.
