# 🏎️ 우리 반 카트 그랑프리

학생들이 **별명만으로** 함께 달리는 3D 카트 레이싱 게임입니다.
파일 하나(`index.html`)로 끝나며, 외부 라이브러리·CDN을 전혀 쓰지 않습니다.
학교 인터넷이 CDN을 막아도, 인터넷이 끊겨도 그대로 돌아갑니다.

## ▶️ 바로 해 보기

| 방법 | 주소 |
|------|------|
| GitHub Pages | `https://dasooni-jpg.github.io/geulssugi-mirror/kart/` |
| 로컬 파일 | `kart/index.html`을 크롬으로 열기 (더블클릭) |

**성공 화면**: 어두운 남색 배경에 “우리 반 카트 그랑프리” 제목과
별명 입력칸·카트 색 8개·모드 카드 4장이 보이면 정상입니다.
별명을 넣고 **🤖 혼자 달리기 → 🏁 출발!** 을 누르면 3·2·1 카운트다운 뒤 경기가 시작됩니다.

## 🎮 네 가지 모드

| 모드 | 인원 | 필요한 것 | 설명 |
|------|------|-----------|------|
| 🤖 혼자 달리기 | 1명 | 없음 | 컴퓨터 카트 7대와 대결. 인터넷 없이도 됨 |
| 👥 둘이 나눠 달리기 | 2명 | 키보드 1개 | 한 기기 화면을 위아래로 나눠 두 명이 대결 |
| 🌐 친구들과 함께 달리기 | 최대 8명 | 아래 서버 1회 설치 | 방 번호 6자리로 모여 실시간 대결 |
| ⏱️ 기록 도전 | 1명 | 없음 | 내 최고 기록이 유령 카트로 함께 달림 |

경기장 3종(눈꽃 스타디움 · 초록 언덕 서킷 · 노을 사막 협곡), 바퀴 수 1~5,
컴퓨터 실력 3단계, 아이템 켜기/끄기, 화면 품질 3단계를 고를 수 있습니다.

## ⌨️ 조작

| 키 | 하는 일 |
|----|---------|
| `↑` `W` | 달리기 |
| `↓` `S` | 브레이크 · 후진 |
| `←` `→` | 방향 돌리기 |
| `Space` | 드리프트 (길게 누를수록 부스터가 모임) |
| `Shift` `E` | 아이템 쓰기 |
| `C` | 시점 바꾸기 (뒤 / 멀리 / 1인칭) |
| `R` | 길 위로 되돌리기 |
| `Esc` `P` | 잠깐 멈춤 |

패드·휴대폰은 화면 아래 버튼으로 조작합니다(자동으로 나타납니다).
둘이 나눠 달리기는 1번이 `W A S D` + `왼Shift` + `Q`, 2번이 방향키 + `Enter` + `/` 입니다.

## 🌐 “친구들과 함께 달리기” 서버 붙이기 (1회)

이 모드만 서버가 필요합니다. Cloudflare Workers 무료 요금제로 충분합니다.

1. Cloudflare → **Workers & Pages → Create → Worker** (이름 예: `kart-rooms`)
2. 저장소의 `kart-online-worker.js` 내용을 편집기에 그대로 붙여넣고 **Deploy**
3. **Settings → Durable Objects** 바인딩 추가
   - Variable name: `KART_ROOM` (반드시 이 이름)
   - Class name: `KartRoom`
   - 무료 요금제에서는 **SQLite 방식**(`new_sqlite_classes`)을 골라야 합니다
4. 배포 주소(예: `https://kart-rooms.내계정.workers.dev`)를 확인
5. 학생이 주소를 넣지 않아도 되게 하려면 `kart/index.html`에서 아래 한 줄을 고칩니다.
   ```js
   const DEFAULT_SERVER = '';   // ← 여기에 배포 주소를 넣으면 학생은 입력할 필요가 없습니다
   ```
   고치지 않으면 학생 화면의 **[접속 서버]** 칸에 주소를 한 번 넣고 “주소 저장”을 누르면 됩니다
   (그 기기에 기억됩니다).

**수업 흐름**: 한 명이 *방 만들고 번호 받기* → 칠판에 6자리 번호 판서 →
나머지는 *들어가기* → 방장이 경기장·바퀴 수를 고르고 **모두 출발!**

서버가 없어도 나머지 세 모드는 그대로 됩니다. 오가는 것은 별명·카트 색·카트 좌표뿐이며,
모두 나가면 방은 저절로 사라지고 아무 기록도 남지 않습니다.

## 🔒 개인정보 (설계 원칙)

- 저장하는 것: **별명(최대 8글자)** 과 카트 색뿐입니다.
- 실명·사진·이메일·전화번호는 **입력받지도, 저장하지도 않습니다.**
- 최고 기록과 유령 카트 데이터는 **그 학생의 기기(브라우저)** 에만 남습니다.
- 서버는 방이 살아 있는 동안만 좌표를 중계하며, 아무것도 기록하지 않습니다.

## 🧰 교실에서 쓸 때 팁

- **기기가 느릴 때**: 경기 준비 화면에서 *화면 품질 → 낮음*. 관중과 나무가 줄어 훨씬 가벼워집니다.
- **시간이 짧을 때**: *1바퀴* 또는 *2바퀴*로 두면 한 판이 40초~1분 30초입니다.
- **소리**: 오른쪽 위 `🔊` 버튼으로 끌 수 있고, 그 선택은 기기에 기억됩니다.
  (교실 전체가 켜면 시끄러우므로 헤드폰이 없으면 꺼 두는 편이 좋습니다.)
- **실력 차가 클 때**: *컴퓨터 실력 → 쉬움*, *아이템 사용* 으로 두면 뒤처진 학생에게 좋은 아이템이 더 자주 나옵니다.
- **공정한 대결이 필요할 때**: *순수 실력전* 으로 두면 아이템이 나오지 않습니다.

## 🛠 만든 방식 (고치고 싶을 때)

`index.html` 하나에 다음이 순서대로 들어 있습니다. 모두 한국어 주석이 달려 있습니다.

| 부분 | 내용 |
|------|------|
| 화면 스타일 | HUD·메뉴 CSS |
| 1. 행렬·벡터 수학 | 직접 만든 4×4 행렬 계산 |
| 2. WebGL 렌더러 | 셰이더, 메시 빌더, 그리기 |
| 3. 경기장 만들기 | 조종점 → 스플라인 → 등간격 표본 |
| 4. 경기장 메시 | 도로·연석·방호벽·지형·관중석·풍경 |
| 5. 카트 | 모양 · 주행 물리 · 컴퓨터 운전수 |
| 6. 경기 진행 | 카메라 · 그리기 · 아이템 |
| 7. 조작·HUD·소리 | 키보드/터치, 속도계, 미니맵, 효과음 |
| 8~10. 온라인·화면 흐름 | 방 접속, 메뉴, 매 프레임 갱신 |

경기장을 새로 만들려면 `TRACKS` 배열에 조종점 `pts`(닫힌 고리)와 색 설정 `env`를 하나 더 넣으면 됩니다.
