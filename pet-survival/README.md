# 🐾 다람쌤 펫 서바이벌 (합체 디펜스)

쉬는 시간·학급 보상용 1인 플레이 게임입니다. **파일 하나(`index.html`)로 동작**하며
인터넷 연결, 로그인, 개인정보 입력이 전혀 없습니다.

## ▶️ 실행 방법
- `pet-survival/index.html`을 **더블클릭**하면 브라우저에서 바로 열립니다.
- 태블릿·전자칠판에서는 이 저장소를 정적 페이지로 올린 뒤 `/pet-survival/` 주소로 접속하면 됩니다.
- 최고 기록은 그 기기의 브라우저에만 저장됩니다(서버 전송 없음). 저장이 막힌 환경에서도 게임은 정상 작동합니다.

## 🎮 규칙
| 조작 | 설명 |
|------|------|
| **소환** | 코인을 내고 빈 칸에 펫 1마리를 놓습니다. 소환할수록 비용이 조금씩 오릅니다. |
| **합체** | 같은 종류·같은 레벨 펫을 끌어다 겹치면 레벨이 1 오릅니다(최대 Lv8). |
| **이동/교환** | 빈 칸으로 끌면 이동, 다른 펫 위로 끌면 자리가 바뀝니다. |
| **강화** | 코인을 내고 모든 펫의 공격력을 8%씩 올립니다. |
| **목표** | 왼쪽 아래 포털에서 나온 적이 오른쪽 아래 **다람쌤(기지)**에게 닿으면 체력이 깎입니다. 0이 되면 종료. |

펫은 사거리 안의 적을 자동으로 공격하므로 **길에 가까운 바깥쪽 칸이 유리**합니다.
전기펫·바람펫은 조금 드물게 나오는 대신 성능이 좋습니다.

| 펫 | 특징 |
|----|------|
| 🌿 풀펫 | 기본기가 좋음(무난한 공격력·공격 속도) |
| 🔥 불펫 | 한 방이 세고 화상 피해를 남김 |
| ❄ 얼음펫 | 사거리가 길고 적을 느리게 만듦 |
| 🌙 어둠펫 | 공격이 매우 빠르고 가끔 치명타 |
| ⚡ 전기펫 | 번개가 옆의 적에게 최대 2번 튐(연쇄 공격) |
| 💨 바람펫 | 사거리가 가장 길고 맞은 적을 길 뒤로 밀어냄 |

적은 슬라임·바위벌레·도깨비 3종이며, **5웨이브마다 보스**가 나옵니다.

## ⚙️ 난이도 조절
`index.html` 위쪽 `BALANCE` 부분의 숫자만 고치면 됩니다(다른 곳은 건드릴 필요 없음).

```js
const BALANCE = {
  시작코인: 120,      // 늘리면 초반이 쉬워집니다
  기지체력: 100,      // 늘리면 실수해도 오래 버팁니다
  적체력증가율: 1.30, // 1.25로 낮추면 훨씬 쉬워집니다
  준비시간: 7,        // 웨이브 사이 생각할 시간(초)
  ...
};
```

학급에서 쓸 때는 `적체력증가율`을 **1.22~1.26**으로 낮추면 대부분의 학생이 10웨이브 이상 넘깁니다.
