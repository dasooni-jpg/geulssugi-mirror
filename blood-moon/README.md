# 핏빛 성역 (블러드문)

방치형 뱀파이어 서바이버. 한 파일(`index.html`)로 돌아감.

- 원본 위치: 구글 드라이브 `claude-code/blood-moon/index.html`
- 배포 주소: https://bloodmoon.pinkdal1213.workers.dev/
- 저장 키: `localStorage['bloodmoon.sanctum.v1']`

이 폴더는 드라이브 원본을 옮겨 와 변경 이력을 남기는 곳임.

## 유물 개편 (2026-09)

첨부 화면(유물 진열장 · 유물 상세창) 모양으로 유물 탭을 바꿈. **저장 자료는 그대로 호환됨.**

- 유물 탭: 등급별(신화 → 전설 → 영웅 → 희귀) 묶음, 빛나는 받침대 + 별 5칸 + 이름판, 돌파 가능하면 초록 ↑
- 유물 상세창: 등급 띠지, 조각 현황 알약, 현재 → 다음 단계 값 미리 보기, "조각을 N개 모아 활성화하세요." 안내
- ⚡ 모두 돌파: 금화가 싼 단계부터 하나씩 올려, 안 깬 유물이 먼저 깨어나고 고르게 오름
- 장비 탭 ⚡ 착용 장비 고르게 강화: 다음 강화가 싼 장비부터 금화가 닿는 데까지
- 경제(유물 조각 + 금화로 성급 돌파)와 수치는 바꾸지 않음

## 유물 2차 개편 (2026-09)

| 기능 | 내용 |
| --- | --- |
| 유물별 조각 | 유물마다 조각을 따로 모아 깨우고 돌파함 (첨부 화면 방식). 필요 수는 `RELIC_CFG.pieces` |
| 유물 가루 | 예전 공용 조각(`S.shard`)의 새 이름. 유물 상자를 열거나, 원하는 유물 조각으로 바꿈 (`dustPerPiece`) |
| 유물 상자 | 젬 30 / 270, 가루 60 / 540. 10회는 전설 이상 1개 보장, 40번 안에 신화 확정. 확률 공개 창 있음 |
| 조각 획득처 | 보스 처치 1~2개, 피의 첨탑 한 층 2개, 유물 상자, 가루로 만들기 |
| 돌파 연출 | 빛 번짐 + 햇살 + 새로 채워지는 별이 돌며 나타남. 신화·5성은 화면 배너 |
| 유물 도감 | 깨운 수 3·6·10·15·20·25·30 에 영구 보너스 + 젬 1회. 한 등급을 모두 깨우면 세트 보너스 |
| 장비 진열 | 장비 보관함도 유물과 같은 받침대 진열장 모양 |

- 예전 저장은 자동으로 옮겨짐. 성급은 그대로, 공용 조각은 같은 개수의 유물 가루가 됨. 처음 켤 때 한 번 안내가 뜸
- 수치는 모두 `RELIC_CFG` · `CODEX` · `CODEX_SET` 에 모아 둠

## 유물 3차 — 밸런스 · 분해 · 무료 상자 · 신화 연출 · 능력치 창

### 밸런스 (5분 한 판 기준 모의실험, 150회 중간값)

학생들은 탐수 허브의 5분 이용권으로 한 판씩 하므로 '판 수'로 속도를 맞춤.

| 목표 | 2차 값 | 3차 값 |
| --- | --- | --- |
| 첫 유물 깨우기 | 4판 | 1판 |
| 도감 10종 | 54판 | 6판 |
| 도감 20종 | 378판 | 22판 |
| 30종 모두 깨우기 | 600판 넘음 | 103판 |
| 30종 모두 3성 | 600판 넘음 | 800판 넘음 (끝판 목표) |

가정: 초반 20판은 한 판에 보스 2 · 웨이브 20, 60판까지는 보스 1 · 웨이브 10, 그 뒤는 보스 0.3 · 웨이브 10.
하루 한 판, 보상함 젬 15 + 무료 상자 1회, 금화는 충분하다고 봄. 실제 플레이와 다를 수 있음.

바뀐 값: 조각 요구량 낮춤, 보스 1~3개, 첨탑 3개, 웨이브마다 25% 확률 1개, 안 깬 유물 3배 잘 나옴,
가루 상자 40/360, 가루로 만들기 12/24/45/90, 분해 환급 40%.

### 새 기능

- 남는 조각 분해: 5성까지 필요한 조각은 남기고, 남는 것만 유물 가루로 바꿈 (유물 탭 · 상세창)
- 보상함 '유물 상자 보급': 하루 1회 무료
- 신화 연출: 카드가 마지막에 따로 등장, 둘레를 도는 불빛, 창 번쩍임, 화면 배너
- 능력치 창: 도감 단계와 등급 세트 보너스를 켜짐/꺼짐으로 표시, 유물 상자 횟수 기록

## 4차 — 저장 코드 · 환생 · 7일 출석 · 첫 안내

| 기능 | 내용 | 위치 |
| --- | --- | --- |
| 저장 코드 | 진행을 `BMZ1:` 로 시작하는 코드로 복사 → 다른 기기에서 붙여넣어 이어 하기 | 설정 |
| 환생 | 10스테이지부터. 핏빛 인장 = 4 × (최고 스테이지/10)^2.2. 인장 1개당 공격력·체력 +15%, 피·금화·경험치 +10% | 월드 맵 맨 위 · 능력치 |
| 7일 출석 | 하루 1번. 빠진 날이 있어도 이어서 받음. 7일째 신화 조각 3 + 젬 50 | 보상함 맨 위 |
| 첫 안내 | 처음 세 판 동안 단추를 하나씩 짚어 줌. 유물·첨탑·환생 안내는 때가 되면 한 번 | 설정 → 처음 안내 다시 보기 |

- 진행은 이 기기(브라우저)에만 저장됨. 기기를 옮기거나 백업할 때는 설정의 저장 코드를 씀.
- 탐수 허브 서버 저장·학급 순위는 만들었다가 선생님 요청으로 취소함 (게임은 외부 서버에 아무것도 보내지 않음).
- 수치는 `REBIRTH` · `ATTEND` 에 모아 둠.

### 함께 고친 결함

- **설정의 '모든 진행 초기화'가 원래 작동하지 않았음.** 첫 누름의 확인 표시가 화면이 다시 그려질 때 사라져
  두 번 눌러도 초기화되지 않았고, 창을 닫는 순간의 자동 저장이 지운 진행을 되살렸음. 둘 다 고침.
- 저장 코드를 불러와 다시 시작할 때도 같은 자동 저장이 받은 진행을 덮어쓸 수 있어 막음.
- 글 입력칸에서 W·A·S·D 가 이동키로 먹혀 글자가 안 써지던 문제를 막음.

## 5차 — 환생 인장 상점 · 저장 코드 QR · 수학 시련

### 수학 시련 (오른쪽 '수학 시련' 단추)

- **6학년 수학 전 단원 12개 · 문제 틀 40개**. 숫자는 풀 때마다 새로 뽑음
  - 1학기: 분수의 나눗셈 · 각기둥과 각뿔 · 소수의 나눗셈 · 비와 비율 · 여러 가지 그래프 · 직육면체의 부피와 겉넓이
  - 2학기: 분수의 나눗셈 · 소수의 나눗셈 · 공간과 입체 · 비례식과 비례배분 · 원의 넓이 · 원기둥, 원뿔, 구
  - 2022 개정 검정 교과서는 출판사마다 단원 이름·순서가 조금 다를 수 있음. `MATH_CFG.units` 의 `on` 으로 단원을 끄고 켬
- **단계형 서술형**: 문장을 읽고 풀이 과정 ①②③ 칸을 차례로 채움. 칸마다 답이 정해져 있어 기계로 채점함 (생성형 AI 안 씀)
- 답 입력: `3/4`, `1과 3/4`, `1 3/4`, `0.75`, `1,200` 모두 받음. 단위는 안 써도 됨. 원주율 3.14
- 틀리면 칸마다 정답과 풀이를 보여 줌. 빈칸이 있으면 채점하지 않음
- 보상: 한 문제마다 유물 가루 +10, **3문제 맞힐 때마다 유물 상자 1회** (하루 5개, 인장 상점 '학자의 인장'으로 늘어남)
- 단원별 정답 기록이 남음
- 검증: 문제 78,000개를 뽑아 답이 모두 양수·유한하고 보여 주는 정답을 그대로 넣으면 맞게 채점되는지 확인함

### 환생 인장 상점

모은 인장은 그대로 기본 효과를 내고, 상점에는 '아직 안 쓴 인장'을 씀 (써도 기본 효과는 줄지 않음).

| 강화 | 효과 |
| --- | --- |
| 핏빛 격노 | 공격력 +20% / 단계 |
| 피의 갈증 | 피 획득 +25% / 단계 |
| 지름길 | 환생 뒤 더 높은 스테이지에서 시작 (최고 기록까지) |
| 빠른 재건 | 환생 뒤 공격력·체력 업그레이드 Lv.5씩 안고 시작 |
| 금고 봉인 | 환생 때 금화 10%씩 남김 |
| 긴 밤 | 방치 보상 최대 시간 +1시간 |
| 붉은 달의 눈 | 유물 상자 전설·신화 비율 +10% |
| 학자의 인장 | 수학 시련 상자 하루 +1개 |

### 저장 코드 QR

- 저장 코드 창에 QR이 함께 나옴 (qrcode-generator 1.4.4, MIT — 파일 안에 줄여 넣음, 인터넷 연결 불필요)
- 코드를 짧게 하려고 장비 이름은 빼고 저장, 불러올 때 되살림
- '📷 QR 찍어서 넣기': 브라우저가 QR 읽기(BarcodeDetector)를 지원하면 카메라로 바로 읽음. 지원하지 않으면 휴대폰 카메라로 찍어 나온 글자를 붙여넣음
- 검증: 실제 저장 40개(코드 569~2,713자)를 QR로 만들어 ZXing 해독기로 모두 정확히 읽음
