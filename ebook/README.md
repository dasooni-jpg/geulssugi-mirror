# 📚 다람쌤 e북 공방

학생이 직접 쓰고 그린 글을 **무료로 진짜 전자책(EPUB)·PDF·웹 책**으로 만드는 사이트입니다.
파일 한 개(`index.html`)로 돌아가며, 서버·회원가입·외부 라이브러리가 없습니다.

## ✨ 주요 기능 (2판)
시중 전자책 제작 도구의 공통 구조(서재 대시보드 → 원고 편집기 → 표지 디자이너 → 내보내기)를 따름.

| 화면 | 할 수 있는 일 |
|------|---------------|
| **내 서재** | 책 표지 카드 목록, 새 책(틀 7가지), 복제·책 파일 저장·삭제, 책 파일 여러 개 한꺼번에 불러오기 |
| **책 정보** | 제목·부제·지은이·펴낸 곳·갈래·**책 소개**(뒤표지와 EPUB 설명에 들어감) |
| **표지 디자인** | 레이아웃 6종 · 색 테마 10종 · 무늬 7종 · 제목 글꼴 8종(명조·고딕·고운바탕·검은고딕·도현·주아·개구·손글씨) · 크기·정렬·색·그림자 · 그림 확대/위치 · **스티커 48종 + 배지·꼬리표 8종** · 제목·지은이·스티커 **끌어서 옮기기**, 크기·회전·복제·맨 앞으로 |
| **본문 스타일** | 클래식·모던·동화책·에세이 4종, 본문 글꼴 3종, 강조 색 |
| **원고** | 종이 모양 편집기, 장/**부(구분 쪽)** 추가, 쪽 모양(보통 글/그림책/시), 서식 단추, 글자 수·예상 쪽수 |
| **미리보기** | 오른쪽에 실제 웹 책 모양(넓은 화면 두 쪽 펼침) |
| **내보내기** | EPUB 3 · PDF(A5/B6/A4, 앞·뒤표지, 쪽 번호) · 웹 책 HTML · 책 파일(.ebook.json), 내보내기 전 자동 점검 |
| **학급 문집 엮기** | 학생 책 파일 끌어다 놓기(여러 개), 같은 책 자동 건너뜀, 순서 바꾸기·가나다순, 작품마다 구분 쪽(학생 표지·제목·지은이), 학생 표지 **모자이크 표지**, 머리말·맺음말 자동, 차례에 지은이 표시 |

### 학급 문집 운영 흐름
1. 학생: 자기 기기에서 책 완성 → **내보내기 → 책 파일 저장** → 클래스룸 등으로 제출
2. 교사: 서재 → **학급 문집 엮기** → 제출 파일을 한꺼번에 끌어다 놓기 → 제목·엮은이 입력 → **문집 만들기**
3. 교사: 편집기에서 머리말·맺음말 작성 → EPUB·PDF로 내보내기

## ▶️ 실행 방법
- **그냥 쓰기**: `index.html`을 더블클릭 → 크롬/엣지에서 열림. 인터넷이 없어도 됨(글꼴만 기본 글꼴로 바뀜).
- **인터넷 주소로 올리기**: `ebook-cloudflare.zip`을 풀고 `1-읽어보세요.txt`를 따라 함 (Cloudflare Pages 끌어다 놓기 또는 Worker 붙여넣기, 무료).
- `index.html`을 고친 뒤에는 `node build-ebook-worker.mjs`로 `ebook-worker.js`를 다시 만듦.

## 🔒 개인정보
- 책은 **그 기기의 브라우저(IndexedDB)에만** 저장됨. 서버로 아무것도 보내지 않음.
- 지은이는 별명 사용을 화면에서 안내함. 얼굴 사진은 올리지 않도록 안내 문구 포함.
- 브라우저 기록을 지우면 책도 지워지므로, 중요한 책은 ③의 "책 파일 저장"으로 보관.

## 🧪 검증 내역
- 만들어진 EPUB(단행본, 부·장이 겹친 문집 모두)을 국제 표준 검사기 **EPUBCheck 5.1**로 검사 → 오류 0 · 경고 0
- 1판에서 저장한 책 파일도 그대로 불러와짐(자동 변환)
- 웹 책: 넓은 화면(두 쪽 펼침)·휴대전화 화면(한 쪽) 넘기기, 차례 이동, 글자 크기 조절 확인
- PDF: A5 크기, 표지 한 쪽 가득, 장마다 새 쪽, 쪽 번호 확인

## 🗂 파일
| 파일 | 설명 |
|------|------|
| `index.html` | e북 공방 본체 (이것 하나로 전부 동작) |
| `ebook-worker.template.js` | Worker 틀 |
| `build-ebook-worker.mjs` | `index.html` → `ebook-worker.js` 빌드 |
| `ebook-worker.js` | Cloudflare Worker에 붙여넣는 자동 생성본 |
| `ebook-cloudflare.zip` | 올리기 꾸러미 (방법 A·B + 안내문) |
