# 🦦 탐수학 — app.html (저장소 사본)

이 폴더는 탐수학 앱의 **화면·게임 로직 전체가 담긴 `app.html`** 사본임.
원본 작업 폴더는 선생님 PC(구글 드라이브 동기화)의 `tamsu-app/` 이며, 이 저장소는
Claude 가 코드를 직접 고칠 수 있도록 `app.html` 만 함께 두는 용도임.

## 🆕 학기(1학기·2학기) 구조
- 단원마다 `sem: 1` 또는 `sem: 2` 가 붙어 있음. 공부하기 화면은 고른 학기의 단원만 보여 줌.
- **학년당 1학기 6단원 + 2학기 6단원 = 12단원, 9개 학년 모두 합쳐 108단원**임.
- 학년 버튼 아래 `학기` 줄에서 1학기·2학기를 고름. 학년을 바꿔도 고른 학기는 그대로 유지됨.
- 앱을 여는 달로 기본 학기를 정함 — **3~7월은 1학기, 8월~다음 해 2월은 2학기**가 먼저 보임.
- 배틀·도전장의 단원 목록은 학기로 거르지 않고 그 학년의 12단원을 모두 보여 줌.

### 단원을 더 넣을 때
`app.html` 의 학년 배열(`G1`…`M3`)에 항목을 넣고 **`sem` 을 반드시 함께 적음**. 같은 id 로 `CONCEPTS` 에도 개념 설명을 넣음.

```js
{ id: 'g3u13', sem: 2, name: '단원 이름', emoji: '🍕', gen() {
    const a = ri(2, 9), b = ri(2, 9);
    return Q(`${a} + ${b} = ${bl()}`, N(a + b, [a * b]));
  } },
```

## ⬅️ 개념 화면 뒤로가기
개념 설명 화면 아래에 `⬅️ 단원 고르기` 버튼이 있음. 고른 학년·학기를 그대로 둔 채 단원 목록으로 돌아감.
기기 뒤로가기(안드로이드 버튼·iOS 스와이프)는 기존 `pushNav` 발자국으로 이미 같은 동작을 함.

## 빌드·배포 (선생님 PC에서 진행)
1. 이 저장소의 `tamsu-app/app.html` 을 PC 작업 폴더의 `tamsu-app/app.html` 자리에 덮어씀
   (`get-tamsu-app.ps1` 을 쓰면 내려받기·백업·검사파일 수정까지 한 번에 됨)
2. `powershell -ExecutionPolicy Bypass -File build-tamsu-worker.ps1` 실행
   → `app.html` + `tamsu-app/items/*` + `tamsu-worker.template.js` 를 합쳐 `tamsu-app/tamsu-worker.js` 생성
3. `tamsu-worker.js` 전체를 Cloudflare Worker 편집기에 붙여넣고 **Deploy**

> `tamsu-worker.js` 는 자동 생성물이므로 직접 고치지 않음.
> 워커 템플릿(`tamsu-worker.template.js`)과 아이템 그림(`tamsu-app/items/`)은 이 저장소에 두지 않았으므로,
> 빌드는 반드시 PC 작업 폴더에서 진행함.

## ⚠️ `_test.html` 한 줄 수정 필요
PC 작업 폴더의 `_test.html` 에 단원 수를 고정한 검사가 있음. 108단원으로 늘었으므로 아래처럼 고쳐야 함.

```js
check(unitCount === 108, `단원 수 108개 (실제 ${unitCount}개)`);   // 기존 54 → 108
```

## 검증 기록 (2026-09-06)
- 108단원 × 각 300문제 = **32,400문제** 자동 생성 검사 통과
  (정답 형식·소수 자릿수·정답 판정·덫이 정답과 겹치지 않는지·개념 설명 존재 여부)
- 9개 학년 모두 1학기 6단원 / 2학기 6단원으로 채워진 것 확인
- 실제 브라우저(Chromium)에서 학기 전환, 단원 열기, `⬅️ 단원 고르기` 복귀 동작 확인, 콘솔 오류 없음
