# 🌊 WILD OCEAN — 뗏목 표류기

뗏목 위에서 마을을 키우는 방치형 생존 게임. 파일 하나(`index.html`)로 동작함.

## 실행 방법
- `index.html`을 더블클릭해서 브라우저로 열면 바로 시작됨.
- 저장 데이터는 그 브라우저(기기)에 자동 저장됨.

## 변경 기록
