# 🧩 픽셀 플로우 (Pixel Flow)

색깔 가방으로 도트 그림을 비워 내는 퍼즐 게임. 쉬는 시간·자투리 시간용 학급 게임임.

- **보드 30열 × 33행 = 990칸** (참고한 모바일 게임과 같은 격자 수)
- **도안 31종 × 색 팔레트 14종 → 100단계**
- 파일 하나(`index.html`)로 끝. 설치·인터넷·계정 **필요 없음**
- 학생 개인정보를 **전혀 저장하지 않음**. 진행 기록은 그 기기의 브라우저에만 남음

## ▶️ 실행 방법
`index.html`을 **더블클릭**하면 브라우저에서 바로 열림.
(태블릿·휴대폰에서는 파일을 브라우저로 열거나, 저장소를 정적 호스팅에 올려 주소로 접속)

정상 동작 확인:
1. 첫 화면에 "픽셀 플로우" 로고와 **시작하기** 버튼이 보임
2. 시작하기 → 100칸짜리 단계 목록이 뜨고 1단계만 열려 있음
3. 1단계에 들어가면 그림판에 도트 그림(로켓)이 그려져 있고, 아래에 가방 더미가 보임

## 🎮 규칙
1. 아래 **가방 더미 4곳**에서 맨 앞 가방을 눌러 **손칸(5칸)** 에 담음
2. 손칸의 가방을 누르면 그림판 아래 트랙으로 나가, **같은 색 픽셀**을 숫자만큼 빨아들임
3. 그 색이 다 떨어지면 가방에 남은 숫자는 그냥 버려짐
4. **정해진 가방 개수 안에** 그림을 모두 비우면 성공
5. 적은 개수로 끝낼수록 ★이 늘어남 (★★★ / ★★ / ★)

**요령** — 숫자가 큰 가방을, 그 색이 많이 남았을 때 쓰면 한 번에 많이 지워짐.
당장 쓸모없는 가방은 손칸에 세워 두고 안 써도 됨.

## 🧮 수업에 쓸 만한 점
- 화면 위쪽에 색깔별 **남은 칸 수**가 항상 보임 → "가방 62개면 몇 칸이 남지?" 식의 **뺄셈·어림** 연습이 자연스럽게 일어남
- 가방을 어떤 순서로 쓸지 고르는 과정이 **계획 세우기·되돌아보기** 활동과 연결됨

## 🛠 만들어진 방식 (유지보수 메모)
- 도안 31종은 30×33 격자에 색 번호(`1`~`6`)를 찍은 문자열로 `SPRITES` 배열에 들어 있음
- 색은 `PALETTES`의 14가지 6색 조합에서 골라 씀. 같은 도안도 팔레트가 다르면 다른 그림처럼 보임
- 단계별 가방 구성은 **단계 번호를 씨앗으로 하는 난수**로 만들어짐 → 같은 단계는 언제 열어도 항상 같음
- 가방은 "낭비 0으로 정확히 비울 수 있는 순서"를 먼저 만든 뒤 부풀리고 미끼 가방을 섞는 방식이라,
  **모든 단계가 반드시 풀림**(생성 직후 시뮬레이션으로 최소 가방 수를 구해 제한을 정함)
- 100단계 전체를 자동 플레이로 검증함: 상식적인 전략(가장 많이 지우는 가방 우선)으로 **100/100 성공**

## 🔒 개인정보
이름·사진·계정을 묻지 않음. `localStorage`에 단계별 ★ 기록만 저장하며, 첫 화면의 **기록 지우기**로 지울 수 있음.
